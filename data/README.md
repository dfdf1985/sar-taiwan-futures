# data/

**此目錄刻意留空。**

本研究的輸入資料為台指期／小台分鐘連續月序列，彙整自 **啟書（qishu）** 與
**TOUCHANCE** 兩家商業資料供應商。其授權條款不允許再散布，因此：

- 原始檔 `MTX_continuous_1m_post.parquet` 不隨本專案發布；
- 由其重新取樣而得的 60 分 K 序列（`mtx_60min_adj.csv.gz`、`mtx_bh_ref.csv.gz`）
  在實質上可替代原始資料，**同樣不發布**。

## 如何取得

1. **向供應商購買授權**，取得同規格的分鐘資料後，執行

   ```bash
   python scripts/01_build_data.py /path/to/MTX_continuous_1m_post.parquet
   ```

   即可在此目錄產生回測所需的兩個檔案。資料規格（欄位、換月規則、
   價格調整方式、稽核結果）詳見 `../DATA.md`。

2. **或自建等效序列**：依 `../DATA.md` 第四節的規格，
   以任何合法取得的台指期分鐘資料重建。

3. **只想看程式怎麼跑**：執行

   ```bash
   python scripts/00_make_sample_data.py
   ```

   會在此目錄產生一份**合成的**隨機漫步序列（非真實市場資料），
   足以讓整條流程跑完並產出圖表，但**數字不具任何研究意義**，
   請勿用來對照簡報中的績效。
